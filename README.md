# MineralFilter

Aplicativo para consulta e identificação de minerais.

## Download para Windows

O programa é distribuído em um pacote ZIP disponível na seção Releases deste repositório.

### Instalação

1. Baixe o arquivo ZIP da versão desejada.
2. Extraia todo o conteúdo para uma pasta no computador.
3. Abra `MineralFilter.exe`.

Mantenha os arquivos auxiliares, a planilha de minerais e a pasta de fotos na estrutura fornecida pelo pacote, quando necessários para o funcionamento do programa.
